# 첫 사건·원정 완성도 개선

작업 브랜치: `feat/haribo-story-content`. 운영 배포·main 병합·원격 DB 변경 없음.

## 달라진 플레이

- 젤리 사건의 창고·주방·행사 준비실을 별도 소품과 배경으로 구성했다. 기존 멤버 캐릭터를 재사용하고 배경·장부·가루·상자·리본은 저장소에서 렌더링하는 SVG로 만들었다. 새 비트맵 이미지 생성이나 외부 이미지 호출은 없다.
- 기본 안내에서 정답 순서를 감추고 필요할 때 여는 힌트로 분리했다. 시계 표시창·상자 표찰 등 실제 관찰할 사실은 남겼다. 조사 위치 강조도 사용자가 켤 수 있다.
- 수집→증거 연결→사건 복원 진행 상태가 보인다. 최종 복원 조각은 증거 연결을 마친 뒤에만 공개해 초반에 결말이 드러나지 않게 했다.
- 방·선택 대원·지도 칸·장부 조각·입력값·선택 증거를 기기에 보존한다. 새로고침과 화면 갱신 뒤에도 복원된다. 기기 저장이 차단되면 같은 페이지의 메모리 저장을 사용하며 기본 플레이는 가능하다.
- 조사·회전·대원 배치·특기·증거 저장은 페이지 전체 이동 대신 해당 게임 화면을 갱신한다. 화면 위치를 유지하고 변한 지도 칸을 짧게 강조한다. 움직임 줄이기 설정을 존중한다.
- 오답 때에는 확대 창과 조립 배치를 유지해 수정할 수 있다. 요청 중 중복 제출을 막고 서버의 기존 revision 검사도 유지한다. 연결 실패/12초 시간 초과 때에는 POST를 자동 재전송하지 않고 현재 서버 저장 상태를 GET으로 확인하도록 안내한다.

## 대원 역할

| 역할 | 실제 효과 |
| --- | --- |
| 탐색가 | 이웃 안개 칸이 길인지 수풀인지 미리 표시. 안개 해제·현장 발견·보상은 발생하지 않는다. |
| 수호자 | 일반 탐사로 막힌 지형을 밝혀도 체력 피해가 없다. 기존 패시브 유지. |
| 마법사 | 발견한 길 조각 하나를 원래 방향으로 정렬한다. |
| 기록가 | 길 조각에 원래 북쪽 방향을 탁본한다. 플레이어가 회전시켜 방향을 맞출 수 있다. |
| 협상가 | 연결된 길 이웃의 안개 한 칸을 시간·체력 소모 없이 밝힌다. |
| 치유사 | 구급 치료로 체력 2 회복. 현장 완료 시 체력 1 회복하는 기존 효과도 유지. |

능동 특기는 **역할별 원정당 한 번**이다. 같은 역할의 대원을 여러 명 데려와도 횟수가 늘지 않는다. 사용 가능 위치·대원·이미 사용한 특기·상태는 서버에서 검증한다. 어떤 특기도 젤리나 경험치를 직접 지급하지 않는다.

## 수정 파일

- `src/views/jelly-scene.tsx`: 세 공간의 배경과 조사 소품.
- `src/views/tactile.tsx`: 단계 표시, 힌트·관찰 자료 분리, 역할 설명·특기 버튼, 지도 미리보기·탁본 표시.
- `public/tactile.js`: 조립 중 저장·복원, 부분 화면 갱신, 중복 제출 제한, 실패 시 읽기 재확인, 지도 변화 강조.
- `public/styles.css`: 장면·소품·수사 진행·모바일·상태 피드백 스타일.
- `public/app.js`, `src/views/layout.tsx`, `src/views/story.tsx`: 전체 페이지 로딩 표시와 게임 내부 갱신 충돌 방지, 새 정적 파일 버전 로드.
- `src/tactile.ts`, `src/story.ts`, `src/story-db.ts`, `src/index.tsx`: 특기 상태·조건·입력 검증 및 기존 저장 데이터 호환. 기존 D1 원자성·지급 한도·KST 처리는 유지.
- `test/tactile.test.ts`: 역할별 효과·역할 중복 사용 차단·고립 칸 차단·동시 요청·보상 없음·잘못된 저장 상태 검사.
