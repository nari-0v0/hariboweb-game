# 머지 이후 빙고·팀 퀘스트 검토

## 임시 빙고 기간의 통화가 팀 퀘스트 짝 선정에서 빠짐

[빙고 집계](../src/bingo.ts#L226-L272)는 주기를 모를 때 w로 시작하는 임시 주 ID로 함께한 시간을 기록한다. [짝 선정](../src/team.ts#L51-L73)은 bingo_periods에 등록된 ID만 조회한다. 임시 주는 이 테이블에 등록되지 않는다.

봇이 시즌 정보를 보내지 못하는 동안 A와 B가 10분을 함께 통화한 뒤 새 시즌이 시작되면, 두 사람은 개별 통화 이력에는 잡히지만 짝의 함께한 시간은 0분으로 계산될 수 있다. 이미 함께한 사람을 새 짝으로 선정할 수 있다. 짝 선정은 빙고판 ID에 의존하지 않고 실제 통화 기간으로 조회하도록 검토한다.

## 지난 빙고 복구가 중간의 임시 기간에서 멈춤

[지난 빙고 재확인](../src/bingo.ts#L448-L457)은 현재 기간 시작 바로 전의 단일 기간만 조회한다. 실제 기간 A가 일요일 저녁에 끝나고 다음 실제 기간 B가 월요일 저녁에 시작하면, B 시작 직전은 월요일 임시 주다. A의 보상 저장이 실패했던 사람이 B 시작 후 처음 빙고를 열면 A 종료 후 7일 이내여도 A의 보상을 확인하지 않는다. 재확인 기간 내 미정산 기록이 있는 실제·임시 기간을 대상으로 테스트한다.

## 기존 임시 빙고 기록 전환

[임시 주 ID 변경](../src/bingo.ts#L47-L57)은 기존 날짜 키에 w를 붙인다. 적용 시점에 임시 주를 사용 중이었다면 이미 쌓인 칸과 보상 이력이 옛 키에 남고 화면은 새 키를 읽는다. 날짜 키는 실제 주기도 사용하므로 이전 기록을 옮길 때 실제 기간과의 충돌을 확인해야 한다. 기존 키에 저장된 데이터로 업그레이드하는 테스트를 추가하는 것이 좋다.
