# 봇 → 웹 동기화 규칙

하리보봇(haribo-bot3)이 일정 간격(예: 10분)마다 모아 둔 활동을 웹으로 보내요.

```
POST {PUBLIC_URL}/api/bot/sync
Authorization: Bearer {BOT_SYNC_SECRET}
Content-Type: application/json
```

## 본문

```json
{
  "batch_id": "2026-10-30T10:10:00Z-1",
  "members": [
    { "id": "디스코드ID", "name": "서버 닉네임", "avatar_url": "https://cdn.discordapp.com/...", "joined_at": "2026-01-01T00:00:00Z", "is_newbie": false }
  ],
  "removed": ["서버를 나간 사람 ID"],
  "pair_xp": [
    { "a": "ID", "b": "ID", "xp": 30, "voice_seconds": 1800, "scrims": 0, "at": "2026-10-30T10:00:00Z" }
  ],
  "solo_xp": [ { "id": "ID", "xp": 20 } ],
  "jelly_earned": [ { "id": "ID", "amount": 1 } ]
}
```

- `batch_id`: 묶음마다 새 값이고 **만든 시각(UTC ISO)으로 시작**해야 해요(예: `2026-10-30T10:10:00Z-1a2b`). 같은 값을 다시 보내면 `"result": "duplicate"`로 무시돼요. 실패해서 다시 보낼 때는 같은 값을 쓰면 두 번 쌓이지 않아요. 기록은 30일 보관이라, 시각이 없거나 25일보다 오래됐거나 하루 넘게 미래인 묶음은 `"result": "stale"`로 받지 않아요.
- `members`: 이번 묶음의 `pair_xp`, `solo_xp`에 나오는 사람은 꼭 여기에도 넣어요. 웹에 없는 사람이나 떠난 사람의 경험치는 버려져요. 하루 한 번은 서버 전체 멤버를 보내면 이름과 프로필이 맞춰져요. 처음 보는 멤버는 이때 캐릭터가 정해져요.
- `members[].jelly`: 더 이상 쓰지 않아요(예전 겜블 젤리 잔액). 와도 무시해요.
- `removed`: 서버를 나간 사람. 본인 카드·도감·젤리·게임 기록·산 기록(남은 닉네임 변경권 포함)·젤칩은 지워지고, 다른 사람이 가진 그 사람 카드는 "떠난 멤버"로 흐리게 남아요. 다시 들어오면 `members`에 넣기만 하면 돼요. 본인 기록은 처음부터, 다른 사람 도감 속 카드는 다시 살아나요.
- `pair_xp`: 두 사람이 함께한 활동. 양쪽 카드에 똑같이 더해져요. `at`은 함께한 시각이고, 처음 만난 날은 가장 이른 값으로 남아요.
- `solo_xp`: 혼자 한 활동(출석, 서바이벌)으로 내 카드에 더할 경험치. 빙고 줄 경험치는 웹이 알아서 줘요.
- `jelly_earned`: 봇이 센 **도감 젤리**(겜블 젤리와 상관없음). 출석 1개, 하루 통화 3시간 3개. 한 줄에 1~100개. 같은 `batch_id` 안에서만 더해져서, 다시 보내도 두 번 쌓이지 않아요. 카드 10레벨마다 3개씩 주는 젤리와 처음 선물 5개는 웹이 알아서 줘요.
- 목록마다 한 번에 5000개, 경험치는 한 줄에 100,000까지예요. 모든 값은 0 이상의 정수예요.

### 시즌 팀·빙고용 (없어도 돼요)

```json
{
  "season": { "start": "2026-11-02T15:00:00Z", "end": "2026-11-16T15:00:00Z" },
  "full_members": true,
  "members": [ { "id": "ID", "name": "...", "is_newbie": false, "games": ["리그 오브 레전드", "발로란트"] } ],
  "room_minutes": [ { "at": "2026-11-03T12:01:00Z", "room": "통화방 ID", "members": ["ID", "ID"] } ],
  "scrims": [ { "id": "내전 ID", "game": "lol", "at": "2026-11-03T12:00:00Z", "members": ["ID"] } ],
  "attendance": [ { "id": "ID", "day": "2026-11-03" } ]
}
```

- `season`: 지금 커뮤니티 주기(2주)의 시작과 끝(UTC). 묶음마다 보내요. 시즌 이름은 시작 날의 한국 날짜예요(예: `2026-11-03`). 길이는 1~92일까지 받아요(봇 생존 주기 최대 90일).
- `full_members`: 이 묶음의 `members`가 서버 멤버 전부일 때 `true`. 웹은 처음 보는 시즌을 이런 묶음에서만 만들어요(게임 역할을 다 알아야 해서). 봇은 시즌이 바뀌면 바로 멤버 전부를 보내요.
- `members[].games`: 그 사람이 가진 게임 역할 이름. 빼면 웹에 있던 값을 그대로 둬요.
- `room_minutes`: 1분마다 2명 이상 있던 통화방(잠수방·헤드셋 끈 사람 빼고). 팀 퀘스트(같이 통화한 짝), 서버 퀘스트(초록하리보와 통화한 시간), 빙고 칸을 여기서 세요.
- `scrims`: 열린 내전과 참가자(참가만 세요). 내전 퀘스트는 웹 설정 `SCRIM_QUESTS=1`일 때만 뽑아요(기본은 꺼짐).
- `attendance`: 출석한 사람과 한국 날짜.
- `room_minutes`와 `attendance`는 주간 빙고 칸도 채워요(아래 "주간 빙고"). `room_minutes`는 팀 퀘스트·서버 퀘스트와 칭찬하기용 "오늘 같이 통화한 사람"(`pair_day`)도 채워요.
- 모두 같은 `batch_id` 안에서 한 번만 더해져요.

## 응답

- `200 {"ok":true,"result":"applied"}` 또는 `"duplicate"`
- `200 {"ok":true,"result":"stale"}`: 묶음이 반영되지 않았어요. 같은 묶음은 다시 보내지 않고, 전체 멤버 동기화가 필요하면 새 묶음으로 보내요.
- `400 {"error":"..."}` 형식이 틀림 (아무것도 반영되지 않음)
- `401` 비밀 값이 틀림

## 젤리 상점 (도감 젤리)

상점은 **도감 전용 젤리**로만 사요. 도감 젤리는 웹(D1)에만 있고, 하리보봇 겜블 지갑이나 겜블관리, 아케이드 켜기/끄기와는 상관없어요. 웹이 그 자리에서 잔액을 확인하고, 젤리를 빼고, 물건을 주는 걸 한 번에 해요. 그래서 봇이 할 일은 없어요.

- 모으는 법:
  - 처음 한 번 5개 (계정당 한 번. 나갔다 다시 와도 또 받지 않아요)
  - 출석 1개, 하루 통화 3시간 3개 (봇이 `jelly_earned`로 보내요)
  - 도감 카드가 10레벨 오를 때마다 3개 (웹이 줘요)
  - 칭찬을 받으면 1개 (하루 3개까지, 웹이 줘요)
- 예전 봇이 쓰던 `GET /api/bot/purchases`는 늘 빈 목록 `{"purchases":[]}`을 돌려줘요. 결과를 보내던 `POST /api/bot/purchases/<번호>`는 없어졌어요.

### 예전 겜블 젤리 결제 돌려주기 (한 번만)

도감 젤리로 바뀌기 전(2026-11-01)에 겜블 젤리로 이미 산 것은 겜블 젤리를 돌려줘요. 산 물건은 그대로 가져요.

- `GET /api/bot/refunds` → `{"refunds":[{"id":"<결제번호>","user":"<디스코드 ID>","item":"theme:mint","price":30}]}` (한 번에 50개까지)
- 봇이 겜블 지갑에 젤리를 넣은 뒤 `POST /api/bot/refunds/<결제번호>` → `{"ok":true,"changed":true}`. 두 번 불러도 괜찮아요.
- 봇은 거래번호 `dogam-web-refund:<결제번호>`로 한 번만 넣고, 목록이 비면 멈춰요. 알림(DM·채팅·관리자 로그)은 보내지 않아요.

### 디스코드 물건 (벌점·경고 지우기, 닉네임 변경권)

도감 젤리로 사면 웹이 젤리를 먼저 빼고, 봇이 디스코드(겜블 계정의 벌점·경고·가방)에 적용해요. 겜블 젤리는 쓰지 않아요.

- `GET /api/bot/services` → `{"services":[{"id":"<결제번호>","user":"<디스코드 ID>","kind":"penalty"|"warning"}]}` (한 번에 20개까지)
  - `penalty`: 벌점 1점 빼기, `warning`: 경고 1점 빼기 (봇의 벌점·경고 저장소에서 빼요. 겜블 계정과 상관없어요)
  - `nickname`은 이제 오지 않아요. 도감 닉네임 변경권은 웹에 남고, 쓸 때 아래 `/api/bot/nicks`로 와요(겜블 변경권과 따로)
- 봇이 적용한 뒤 `POST /api/bot/services/<결제번호>` `{"ok":true}` → 끝남. 지울 게 없으면 `{"ok":false,"reason":"no_penalty"|"no_warning"}` → 웹이 도감 젤리를 돌려줘요.

### 도감 닉네임 변경권
- `GET /api/bot/nicks` → `{"nicks":[{"id":"<신청번호>","user":"<디스코드 ID>","front":"<새 닉네임 앞부분>"}]}` (20개까지)
- 봇은 서버 닉네임 규칙으로 앞부분만 바꾸고(칭호·생년 그대로) `POST /api/bot/nicks/<신청번호>` `{"ok":true}`.
  못 바꾸면 `{"ok":false,"reason":"invalid"|"banned"|"forbidden"|"left"}` → 변경권은 그대로 남아요.
- 두 번 불러도 한 번만 처리돼요. 봇은 거래번호 `dogam-svc:<결제번호>`로 같은 결제를 두 번 적용하지 않아요. 잠깐 못 하는 경우(겜블 점검 등)는 결과를 보내지 않고 다음에 다시 해요.
- 값: 벌점 100, 경고 200(살 때마다 1.5배, 올림), 닉네임 변경권 5. 웹 `src/shop.ts`의 `SERVICES`.

물건 번호는 `theme:<테마>`, `deco:<꾸밈 캐릭터>`이고 값은 웹 `src/shop.ts`에 있어요. 판타지 꾸밈 캐릭터는 젤리로 못 사고 도감 카드를 모으면 열려요(필요한 장수는 서버 인원에 맞춰 바뀌어요, `rewardNeed`).

## 도감 칭호 (닉네임 앞 `「칭호」 `)

멤버가 웹 `/titles`에서 칭호를 고르면 하리보봇이 디스코드 닉네임 앞에 `「칭호」 `로 붙여요. 칭호는 4글자까지이고 띄어쓰기·대괄호가 없어요(웹 `src/titles.ts`).

- `GET /api/bot/titles` → `{"titles":[{"user":"<디스코드 ID>","id":"ace","title":"ACE"}]}` (바꿀 멤버만, 한 번에 50명까지). 칭호를 뗄 때는 `{"user":"…","id":"","title":null}`.
- 봇이 닉네임 앞 칭호만 바꾼 뒤 `POST /api/bot/titles/<디스코드 ID>` `{"id":"ace","ok":true}`. 못 붙이면 `{"id":"ace","ok":false,"reason":"too_long"|"forbidden"|"left"}`.
  - `too_long`: 칭호를 붙이면 32자를 넘어요(예전 칭호만 떼요). `forbidden`: 봇보다 높은 역할이에요. `left`: 서버에 없어요.
  - 그 사이 멤버가 다른 칭호를 골랐으면 다음 목록에 다시 나와요. 잠깐 실패(디스코드 오류)는 결과를 보내지 않고 다음에 다시 해요.
- 닉네임 변경권과 닉네임 규칙 검사는 칭호를 떼고 봐요. 변경권은 닉네임만 바꾸고 칭호는 그대로 다시 붙여요(변경권 화면에는 칭호가 안 보여요).
- 동기화 `members[].name`은 칭호를 뗀 이름이에요. 웹도 한 번 더 떼요.

## 경험치 기준 (제안, 봇에서 정해요)

레벨 L이 되려면 누적 4.5 × (L-1)² XP(올림)가 필요해요. Lv.10 = 365, Lv.20 = 1,625, Lv.30 = 3,785, Lv.50 = 10,805, Lv.100 = 44,105. 만렙은 100이고, 한 사람과 하루 1시간씩 놀면 약 2년이 걸려요.

| 활동 | XP |
|---|---|
| 같은 통화방에 함께 1분 | 1 (한 쌍당 하루 180까지) |
| 같은 내전에 함께 참가 | 30 |
| 출석 | 20 |
| 서바이벌 하루 생존 | 10 |
| 빙고 한 줄 | 30 (웹이 줘요) |

관계 이름은 첫 만남(1) → 친구(10) → 절친(30) → 단짝(60) → 평생 단짝(100)이에요. 다른 경험치 없이 하루 3시간씩 같이 통화하면 3일째 친구, 22일째 절친, 88일째 단짝이 돼요.

## 디스코드 고정 패널

봇이 디스코드 채널에 고정 패널을 두고, 버튼을 누른 사람에게만 보이는 창으로 답해요. 모두 `Authorization: Bearer {BOT_SYNC_SECRET}`가 필요해요.

- `GET /api/bot/card/<디스코드ID>` → 내 카드 정보. 서버에 없는 사람은 `404 {"error":"not_member"}`.
  ```json
  { "id": "ID", "name": "닉네임", "intro": "", "level": 12, "level_name": "친구", "ratio": 0.35,
    "tier": "silver", "tier_label": "은색", "jelly": 45, "dogam": { "owned": 23, "total": 58 },
    "best": { "id": "ID", "name": "젤리곰", "level": 12 }, "praise_left": 2,
    "praise_box": { "unread": 1, "total": 4, "items": [{ "day": "2026-11-12", "date": "11월 12일", "note": "오늘 캐리 고마워요", "unread": true }] },
    "palette": { "rim": "#6b7a90", "body": ["#eef2f8", "..."], "ring": ["#f4f7fb", "#9aa8bc"], "sky": ["#a9dcff", "#e6f6ff"],
                 "ground": "#8fd67a", "plate": ["#ffffff", "#dfe5ee"], "ink": "#2a2030", "sparkle": false },
    "character_url": "https://.../char/girl-01-0.png", "page_url": "https://.../me" }
  ```
  `palette`는 웹 카드와 같은 색이에요(`src/palette.ts`). 봇은 이 색으로 디스코드용 카드 그림을 그려요.
  `praise_box`는 칭찬함이에요. 최근 5개, 보낸 사람은 없어요(DB에만 있어요). `note`가 `null`이면 한마디 없는 칭찬이거나 받은 사람이 숨긴 한마디예요. 디스코드 패널은 일부만 보여 주므로 읽음 표시는 웹 칭찬함에서만 해요. 화면 안내는 "받는 사람에게는 보낸 사람이 보이지 않아요."만 써요.
- `GET /api/bot/praise/<디스코드ID>` → `{"given":["오늘 이미 칭찬한 ID"],"left":2,"partners":[{"id":"ID","minutes":42}]}`
  - `partners`: 웹에 쌓인 `room_minutes`로 본 오늘(한국 날짜) 같이 통화한 사람. 봇은 오늘 기록을 메모리에만 들고 있어서 재시작하면 비니까, 봇 기록과 이 목록을 합쳐서 칭찬할 사람을 보여 줘요. 웹은 하루치 짝만 3일 동안 남겨요.
- `POST /api/bot/praise` `{"from":"ID","to":"ID","note":"한마디(선택, 100자)"}` → `{"result":"done","jelly":true,"left":2,"note":"sent"}`
  - `note`(응답): `sent`(한마디도 전함), `filtered`(비꼬기·욕이라 한마디는 빼고 칭찬만 전함), `none`(한마디 없음 또는 칭찬이 안 됨). 한마디는 Workers AI(무료 사용량)로 검사하고, AI가 없거나 한도가 끝나면 욕설 단어 검사만 해요.
  - `result`: `done`, `already`(오늘 이미 그 사람에게 줌), `limit`(오늘 3번 다 씀), `self`, `not_member`
  - 오늘 같이 통화했거나 내전을 뛴 사람인지는 봇이 확인하고 보내요(봇 기록 + 위 `partners`).
  - 하루(한국 날짜) 3번, 같은 사람에게는 하루 1번. 받은 사람은 하루 3개까지 칭찬 1번에 도감 젤리 1개를 받아요(`jelly`).
  - 알림(DM·채팅)은 보내지 않아요.

## 시즌 팀 (팀 퀘스트·서버 퀘스트)

시즌(생명력 주기 2주)마다 최근 2주 동안 활동한 멤버를 게임 역할과 노는 시간대가 겹치는 사람끼리 10명 안팎의 팀으로 나눠요. 팀 인원 차이는 1명까지이고, 승인된 "같이 배정되지 않기" 짝은 다른 팀에 넣어요. 시즌 중에 처음 활동한 사람은 게임 역할이 겹치는 제일 작은 팀에 들어가요.

- **팀 퀘스트**(빙고 가운데 칸): 지난 2주간 10분 미만 같이 통화한 팀원과 이번 시즌 같은 통화방에서 30분 함께하면 달성. 목표는 처음 후보의 절반(반올림, 최소 2명)이에요. 팀원이 떠나면 남아서 달성했거나 달성할 수 있는 후보 수까지 목표를 낮춰요. 처음 후보가 2명 미만이거나 남은 후보가 없으면 가운데 칸은 보너스 칸이에요(팀 퀘스트 보상 없음).
- **서버 퀘스트 "초록하리보 납치 대소동!"**: 초록하리보(`is_newbie`)와 같은 통화방에서 30분 함께하면 납치 성공. 목표 수를 채우면 참여한 사람 모두 보상.
- 보상은 시즌이 끝날 때 목표를 채웠으면 직접 달성·참여한 사람만: 팀 퀘스트 도감 젤리 3, 서버 퀘스트 도감 젤리 5(+ 젤리피 기록). 웹이 알아서 줘요.
- 예전 "모둠 퀘스트 8개"와 모둠 칭호는 이제 만들지 않아요(웹 설정 `groupQuests`를 켠 테스트에서만).

- `GET /api/bot/team/<디스코드 ID>` → 고정 패널 "우리 팀".
  ```json
  { "season": { "start": "…", "end": "…" },
    "team": { "no": 3, "members": [{ "id": "ID", "name": "닉네임" }], "target": 4,
              "achievers": [{ "id": "ID", "name": "닉네임" }], "complete": false, "bonus": false, "me": "todo" },
    "server": { "target": 10, "kidnapped": 4, "met": false, "joined": true },
    "rules": { "goal_min": 30, "prior_max": 10, "kidnap_min": 30, "team_jelly": 3, "server_jelly": 5 },
    "page_url": "https://.../bingo" }
  ```
  `team`이 `null`이면 이번 시즌 팀이 없어요. `me`: `done`(나는 달성), `todo`(아직), `team-done`(팀 완료, 나는 아직), `bonus`(보너스 칸). 후보와 짝은 보여 주지 않고 달성한 사람 이름만 보여 줘요.
- `GET /api/bot/teams` → 고정 패널 본문 "팀 순위" 그림용. `{"season": {...}, "ranking": [{"no","rank","done","total","size","complete","bonus"}], "server": {"target","kidnapped","met"}, "page_url": "..."}`. `done`/`total`은 팀 퀘스트 달성 수/목표. 팀 목표를 채운 팀 → 달성 비율 → 달성 수 순이고 보너스 칸 팀은 맨 뒤예요. 시즌이나 팀이 없으면 `"ranking": null`.
- 예전 `GET /api/bot/group/<ID>`, `GET /api/bot/ranking`(모둠 퀘스트용)은 옛 봇을 위해 남아 있지만 새 봇은 쓰지 않아요.
- 알림(DM·채팅)은 보내지 않아요. 고정 패널과 웹 `/bingo`에서만 보여요.

## 하리보 빙고

생명력(커뮤니티) 주기를 반으로 나눈 "이번 주"마다 멤버마다 3×3 빙고판이 하나씩 생겨요. 주기는 봇이 보내는 `season`을 써서 한 주기에 빙고판이 2번 나와요(주기를 아직 모르면 한국 시간 월요일 기준 주로 대신해요). 내 칸 8개(쉬움 3, 보통 3, 어려움 2) + 가운데 칸은 팀 퀘스트예요(위 "시즌 팀"). 빙고판은 기간과 멤버로 정해지는 무작위라 저장하지 않아요. 신청·인증·관리자 확인은 없고, 칸은 저절로 채워져요.

- 채우는 기록: 봇이 보내는 `room_minutes`(통화 시간, 4명 이상 방, 밤 10시~새벽 2시, 주말, 같이 통화한 사람, 한 사람과 통화한 시간, 처음 만난 사람)와 `attendance`(출석), 웹이 아는 칭찬 주기·받기, 패널에서 내 카드 열기(`GET /api/bot/card`), 웹에서 내 카드 보기. 그래서 봇은 `DOGAM_SEASON=1`이어야 통화·출석 칸이 채워져요. 내전 칸은 내전을 쉬는 동안 넣지 않았어요.
- 보상: 한 줄(가로·세로·대각선)마다 도감 젤리 1개 + 내 카드 경험치 30, 9칸을 다 채우면 도감 젤리 3개 더. 줄마다 한 번만 받아요. 동기화 뒤, 칭찬 뒤, 빙고를 볼 때 확인해서 줘요. 지금 서버에 있는 멤버만 받아요.
- `GET /api/bot/bingo/<디스코드 ID>` → 고정 패널 "이번 주 빙고"용. 서버에 없는 사람은 `404 {"error":"not_member"}`.
  ```json
  { "name": "닉네임", "week": { "start": "2026-11-01T15:00:00.000Z", "end": "2026-11-08T15:00:00.000Z" },
    "cells": [ { "icon": "🎧", "text": "통화 3시간", "diff": "normal", "value": 70, "target": 180, "done": false, "unit": "min" } ],
    "lines": [0, 4], "filled": 5, "full": false, "jelly": 2, "xp": 60,
    "rewards": { "line_jelly": 1, "line_xp": 30, "full_jelly": 3 }, "page_url": "https://.../bingo" }
  ```
  `cells`는 왼쪽 위부터 9칸, `lines`는 채운 줄 번호(0~2 가로, 3~5 세로, 6·7 대각선), `unit`이 `"min"`이면 값이 분이에요.
- 알림(DM·채팅)은 보내지 않아요. 고정 패널과 웹 `/bingo`에서만 보여요.

## 같이 배정되지 않기

멤버가 웹 `/bingo`에서 적은 요청을 봇이 비공개 채널에 올리고, 나리가 [승인]/[반려]를 눌러요. AI가 장난·내용 없음으로 거른 요청도 "AI 반려"로 표시해서 올라가고, 나리가 [승인]을 누르면 뒤집혀요. 승인된 짝은 다음 팀 짜기와 시즌 중간 합류에서 같은 팀에 넣지 않아요. 단, 활동한 사람이 적어 팀이 하나뿐이면(나눌 팀이 없으면) 같은 팀이 될 수 있어요. 모두 `Authorization: Bearer <BOT_SYNC_SECRET>`.

- `GET /api/bot/assign-blocks` → `{ "blocks": [{ "id": 1, "from": {"id","name"}, "to": {"id","name"}, "reason": "...", "ai_verdict": "ok|vague|reject|null", "ai_summary": "한 줄 요약|null", "status": "pending|ai_rejected", "created_at": "ISO" }] }`
  - 아직 채널에 안 올린 요청, 오래된 것부터 최대 10개. `status: "ai_rejected"`는 AI가 거른 요청이에요(나리가 승인하면 적용).
- `POST /api/bot/assign-blocks/:id/posted` `{ "message_id": "디스코드 메시지 ID" }` → `{ "ok": true, "changed": true|false }` (처음 한 번만 적혀요. 같은 메시지 ID로 다시 보내면 `changed: true`, 다른 ID면 `false`)
- `POST /api/bot/assign-blocks/:id/decide` `{ "decision": "approve"|"reject", "by": "누른 사람 디스코드 ID" }` → `{ "applied": true|false, "status": "approved|rejected|pending", "decided_at": "ISO|null" }`
  - 대기 중이거나 AI가 거른 요청일 때만 적용돼요. 두 번 눌러도 처음 결정만 남아요(`applied: false`면 이미 처리된 것).
  - 누가 누를 수 있는지(나리만)는 봇이 확인해요.
  - 없는 요청이면 `404`예요. 신청한 사람이 웹에서 [풀기]를 눌렀거나, 둘 중 한 명이 서버를 떠나 지워진 경우예요. 봇은 메시지를 "지워졌어요"로 닫아요.
- 한 사람이 제외할 수 있는 사람은 최대 3명(검토 중 + 승인)이에요. 멤버는 `/bingo`에서 [풀기]로 언제든 바로 지울 수 있어요(승인 없이, 다음 팀 짜기부터 적용).

## 광장 실시간 연결

광장(`/plaza`)은 같이 돌아다니는 지도예요. 봇은 웹소켓 하나로 이어져서 통화방 모습과 통화방 채팅을 보내고, 방 옮기기 요청을 받아요. 아무것도 저장하지 않아요(통화방 모습만 다시 깨어날 때를 위해 광장 안에 들고 있어요).

```
GET {PUBLIC_URL}/api/bot/plaza   (웹소켓으로 업그레이드)
Authorization: Bearer {BOT_SYNC_SECRET}
```

- 연결이 조용하면 끊길 수 있어서 25~30초마다 글자 `ping`을 보내요. 답은 `pong`이에요.
- 봇 연결은 하나만 유지돼요. 새로 연결하면 예전 연결은 코드 4000으로 닫혀요.

### 봇 → 웹

```json
{ "t": "voice", "channels": [ { "id": "통화방ID", "name": "수다방", "limit": 0, "group": "일반통화방", "members": [ { "id": "ID", "name": "닉네임" } ] } ], "elsewhere": ["광장에 안 보이는 방에 있는 사람 ID"] }
{ "t": "chat", "user": "ID", "ch": "통화방ID", "text": "통화방 채팅 한 줄" }
{ "t": "moved", "user": "ID", "ch": "통화방ID", "ok": true, "reason": null }
```

- `voice`: 지금 통화방 전체 모습. 바뀔 때마다 통째로 보내요. 멤버 누구나 볼 수 있는 방만 넣고(최대 30개, 방마다 99명), 운영진 방처럼 숨은 방에 있는 사람은 `elsewhere`에 ID만 넣어요(통화 중인지만 알 수 있게). `limit` 0은 인원 제한 없음. `group`(선택)은 통화방 카테고리 이름이에요. 같은 카테고리 방은 붙여서 보내 주면 광장에서 이름표를 단 구역으로 묶어 보여 줘요. 봇은 `.env` `DOGAM_PLAZA_CATEGORIES`에 적힌 카테고리의 방만 보내요.
- `chat`: 통화방에 딸린 채팅. 웹이 60자로 자르고 줄바꿈을 없애요. 저장하지 않고 말풍선으로만 보여 줘요.
- `moved`: 아래 `move` 요청의 결과. `reason`은 `not_in_voice`, `full`, `no_permission`, `no_room`, `busy`, `bot_no_permission`, `error` 중 하나.

### 웹 → 봇

```json
{ "t": "move", "user": "ID", "ch": "통화방ID" }
```

- 멤버가 광장에서 그 방 구역에 들어가 멈췄을 때 와요. 웹은 그 사람이 지금 통화 중이고 방 근처에 있는지만 확인해요. 봇은 본인만 옮기고, 이미 통화방에 있는 사람만 옮길 수 있어요(디스코드 규칙). 방 권한, 인원 제한, 잠수방을 확인한 뒤 옮겨요.

## 도감 축하

두 사람을 멘션하는 축하 글이 축하 채널에 올라가요(도감에서 유일하게 채널에 올라가는 글이에요).

- `GET /api/bot/cheers` → `{"cheers":[{"a":"<ID>","b":"<ID>","level":30,"name":"절친"}]}` (두 사람 카드가 10레벨마다, 10개까지, 둘 다 지금 멤버일 때만)
- 봇이 /설정의 "도감 축하 알림 채널"에 올린 뒤 `POST /api/bot/cheers` `{"a":"<ID>","b":"<ID>","level":30}` → 같은 축하는 다시 안 와요.
  채널을 안 골랐으면 봇은 가져가지 않아요(밀린 축하는 채널을 고른 뒤 올라가요).
