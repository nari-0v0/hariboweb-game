# 젤리 사건 연결 조사 변경

`사라진 젤리 500개`를 방마다 독립된 정답을 입력하던 방식에서 앞선 발견으로 다음 조사가 열리는 방식으로 변경했다.

## 플레이 흐름

1. 창고 상자를 옮겨 바퀴 자국과 가루를 드러내고 조사·채집한다.
2. 주방에서 설탕과 밀가루 표본을 모두 확대 비교한 뒤 일치하는 표본을 연결한다.
3. 적재 메모와 바퀴 표식으로 행사 준비실의 S-17 수레를 확인한다.
4. 봉인 인쇄선을 맞추고, 다섯 상자를 각각 확인하여 100 × 5 = 500개를 기록한다.
5. 바퀴 자국 → 표본·메모 → 실물 수량 → 운반 장부를 연결하고 승인된 이동 경로를 복원한다.

상자 이동은 끌기와 버튼을 모두 지원한다. 표본 연결과 흐름 복원도 클릭으로 조작할 수 있다. 창고·주방·행사 준비실은 좁은 화면에서도 한 줄이다. 기존 배경과 캐릭터 자산을 재사용하며 표본·봉인·상자는 SVG로 표현했다.

## 파일과 영향

- `src/jelly-investigation.ts`: 단계 상태, 전제 조건, 증거와 결말의 일관성을 정의한다.
- `src/views/jelly-investigation.tsx`, `src/views/jelly-scene.tsx`: 이동 상자, 비교대, 수레·봉인·수량 조사 화면을 제공한다.
- `src/story.ts`, `src/tactile.ts`, `src/story-db.ts`, `src/index.tsx`: 새 버전 및 검증된 조사 동작을 연결한다. 진행 중인 이전 버전 젤리 사건은 장부·리본·조력자 기록을 보존하고 새 조사로 전환한다. 완료 기록은 유지한다.
- `src/views/tactile.tsx`, `src/views/story.tsx`, `src/views/layout.tsx`, `public/tactile.js`, `public/styles.css`: 도구 가방, 단계별 화면, 조작과 임시 배치 복원, 캐시 버전을 반영한다.
- `test/jelly-flow.test.ts`, `test/tactile.test.ts`, `scripts/story-smoke.mjs`: 새 조사와 이전 버전 회귀 검사를 포함한다.

다른 다섯 사건과 원정대의 규칙은 유지한다. 보상 액수·일일 한도·겜블 지갑 분리는 유지하며 새 버전 재완료로 최초 보상을 다시 지급하지 않는다. 기존 D1 원자적 배치와 revision 검증을 사용한다. 스키마 변경, 운영 배포, 알림, 운영자 승인 단계는 없다.

## 확인 결과

- TypeScript 및 브라우저 스크립트 문법 검사 통과.
- 23개 테스트 파일, 189개 테스트 통과.
- 로컬 Workers + D1 실제 HTTP 검사 39개 통과.
- 브라우저에서 상자 이동 버튼부터 표본 비교·연결, 수레, 봉인 슬라이더, 다섯 상자 확인, 증거 연결, 최종 사건 해결까지 완료했다. 기존 보상 수령 계정의 추가 보상 없음도 확인했다.
- 320px 화면에서 방 세 개의 탭 높이가 같고 한 줄이며, 390px 화면에서도 가로 넘침이 없다.
- 화면 기록: `docs/qa/linked-jelly-mobile.png`.

## 남은 확인 범위

실물 휴대폰의 터치 드래그와 운영 Cloudflare D1 환경은 별도 확인이 필요하다. 이번 브라우저 검사는 상자 이동 버튼과 클릭·키보드 조작으로 완료했다. 운영 배포는 수행하지 않았다.
