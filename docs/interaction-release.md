# 하리보 사건파일·원정대 조작형 구현 기록

기준: main `14e34b1`. 작업 브랜치: `feat/haribo-story-content`.
운영 배포·운영 DB 변경·main 병합은 수행하지 않았다.

## 실제 플레이 방식

- **사건파일 6개:** 방 이동 → 물건 확대 → 장부 조립/시계·파형 조절/표찰 읽기/문양 조립 → 증거 카드 연결 → 사건의 흐름 배치. 정답 선택 버튼으로 사건을 끝내는 방식은 새 판에서 사용할 수 없다.
- **원정대 3지역·18현장:** 대원을 골라 이웃 안개 칸 탐사 → 길 조각 회전 → 기지부터 연결된 현장 조사 → 다섯 현장 기록 뒤 최종 목적지 진입. 지역마다 지도 배치와 현장 기록이 다르다. 돌아가는 길도 직접 연결할 수 있다.
- **모바일:** 조각 끌기 대신 조각과 배치 칸을 차례로 누를 수 있다. 키보드로도 같은 버튼을 사용할 수 있다.
- **교차 기록:** 녹슨 열쇠는 상자의 지도, 초대장은 보관소 선물, 봉인 편지·가짜 지도는 탐험가 사건의 추가 조사, 정령과 맺은 약속은 마을 재회, 석문 암호는 유적 문양 기록과 연결된다.
- 멤버는 조사 조력자·탐험 대원이며, 사건의 당사자는 가상 요정·마스코트·탐험가다.

## 저장·경제·시즌

- 진행 저장은 판 ID·사용자·revision·진행 상태를 조건으로 한 비교 후 갱신이다. 갱신을 이긴 요청의 임의 mutation 토큰이 있는 경우에만 같은 D1 batch에서 발견·지급 기록·프로필을 반영한다. 도중 오류는 모두 롤백한다.
- 반복 판은 이야기/지역별 최초 완료 보상을 추가로 지급하지 않는다. 실제 지급에 실패했거나 해당 KST 날짜 한도를 넘으면 최초 보상 권리를 소비하지 않는다.
- 기존 보상 상수(경험치 10, 성공 도감 젤리 1)를 사용하며 안전 귀환은 경험치만 받는다. 스토리의 한도와 기존 모드의 한도를 따로 늘리지 않았다. 겜블 지갑은 접근하지 않는다.
- 완료 날짜는 기존 `kstDay`, 시즌은 완료 시각에 `starts_at <= 완료 < ends_at`인 시즌을 사용한다. 발견은 시즌이 바뀌어도 남는다. 다른 판의 새 발견은 다음 판 시작 시 반영된다.
- 기존 `case_runs`, `exp_runs` 기록은 보존한다. 배포 전 선택형 시제품의 `story_runs` v1 진행 판만 보상 없이 덮고 v2로 새로 시작한다. 완료된 v1 판·발견·지급 이력은 유지하므로 버전 변경으로 최초 보상을 다시 받지 않는다.
- 새 이미지/외부 AI 호출/운영자 승인/외부 알림을 추가하지 않았다. main에는 별도 배경 이미지가 없어 기존 캐릭터 그림과 CSS로 방과 지도를 구성했다.

## 검증

- TypeScript 검사와 JS 문법 검사 통과.
- 전체 22개 테스트 파일, **178개 테스트 통과**. 6사건 복원, 3지역 18현장 연결 완주, 잘못된 조립/연결/접속 차단, 동시 최종 제출, 응답 유실 재전송, 지급 실패 롤백, 기존/신규 보상 한도, KST 자정·시즌 종료 경계 포함.
- 실제 로컬 Cloudflare Workers + D1에서 **HTTP 27개 검사 통과**: 인증, 다른 사이트 요청, 잘못된 형식/크기/중복 입력, 타인 판 소유권, 동시 시작·동시 완료, 선택형 정답 요청 우회 차단.
- 브라우저에서 장부 조립 → 수량 조사 → 증거 연결 → 사건 흐름 복원으로 실제 사건 완료. 원정 대원 파견·안개 해제·길 회전 후 조사 잠금 해제 확인.
- 1280px 데스크톱, 390px·320px 모바일에서 가로 넘침 없음. 로드 실패 이미지 없음.
- 새 화면: `docs/qa/tactile-case-desktop.jpg`, `tactile-map-desktop.jpg`, `tactile-map-mobile.jpg`. `story-*.jpg`는 이전 선택형 시제품의 검증 기록이다.

## 적용 시 확인할 점

- 운영에는 아직 적용하지 않았다. 추후 사용자가 배포를 승인하면 **0016 마이그레이션을 먼저 적용**하고 코드를 배포해야 한다. 앞선 마이그레이션은 수정하지 않았다.
- 화면은 현대 브라우저의 JavaScript·dialog·ResizeObserver를 사용한다. Safari/Firefox 실기기와 실제 원격 D1 환경의 검증은 남아 있다.
- 고정된 6사건·3지역 콘텐츠다. 주기적 무한 콘텐츠 생성은 제공하지 않는다. 새 퍼즐을 추가하거나 정답을 변경할 때는 진행 버전과 증거의 일관성을 함께 관리해야 한다.

로컬 재검사: `npm ci`, `npm run typecheck`, `npm test`.
로컬 서버(DEV_LOGIN 활성화) 실행 후 `node scripts/story-smoke.mjs`로 실제 HTTP를 재검사할 수 있다. 이 스크립트는 localhost에서만 실행된다.
