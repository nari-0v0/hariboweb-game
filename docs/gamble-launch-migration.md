# 하리보 도감 겜블장 출시 이관

## 이관 금액

- 종료 시점에 기존 디스코드 겜블장 지갑에 실제로 반영된 보유 젤리를 기준으로 한다. 1젤리는 웹 겜블장 1젤칩으로 환산한다.
- 계정별 이관액은 `max(0, 보유 젤리 − 잔액에 아직 반영되지 않은 미상환 대출금)`으로 계산한다.
- 예를 들어 종료 시 지갑에 8,000젤리가 있고 잔액에 아직 반영되지 않은 미상환 대출금이 1,000젤리라면 7,000젤칩을 더한다.

## 컷오버 전 확인

- 이관 대상은 기존 겜블장 종료 시점의 서버 멤버 중 기존 겜블장 계정이 있는 사람이다. 디스코드 사용자 ID로 연결하고 웹 멤버 정보가 아직 없는 사람은 누락 건으로 보고한다.
- 자산은 종료 시점의 보유 젤리만 이관한다. 주식, 예금, 적금, 아이템은 별도 환산하지 않는다.
- 보유 젤리에서 종료 시점의 미상환 대출금을 뺀다. 이미 보유 잔액에 반영된 대출·연체 금액은 다시 차감하지 않는다. 차감 후 최종 이관액이 음수면 0젤칩으로 처리하며 웹의 기존 잔액은 차감하지 않는다.
- 기존 겜블장의 실제 운영 원장에서 읽는다. 원장이 PRIMARY로 전환된 서버에서 이전 저장소의 잔액을 대신 읽지 않는다.

## 11월 21일 종료 전까지 도감 겜블장 잠금

하리보 도감은 먼저 공개하고, 도감 겜블장 메뉴에는 잠금 표시와 “기존 겜블장 종료 후 이관이 완료되면 열려요” 안내를 표시한다. 기존 디스코드 겜블장은 11월 21일 종료까지 운영한다.

잠금 중에는 직접 주소로 접속해도 안내 화면을 표시한다. 베팅, 카드 조작, 일일 젤칩 수령과 다시 시작은 서버에서 차단한다. 정확한 종료 시각은 운영 일정에 맞추고, 날짜가 바뀌어도 자동으로 열지 않는다. 잔액 이관과 검증을 마친 뒤 잠금을 해제한다.

기존 상점의 50젤리짜리 일회성 알바 일괄 수령은 [봇 PR #52](https://github.com/nari-0v0/haribo-bot3/pull/52)에서 다룬다. 알바 보상은 종료 전에 지급되어 지갑 잔액에 반영된 금액만 이관액에 들어간다. 미사용 알바 횟수는 별도 환산하지 않는다.

## 기존 겜블장 종료 및 이관 순서

1. 출시 전 드라이런으로 이관 대상 수, 원본 잔액 합계, 미반영 대출금과 최종 이관액 합계, 누락 및 별도 검토 대상을 확인한다.
2. 11월 21일 기존 겜블장 종료 시 기존 겜블장의 베팅·상점·알바 수동/자동 지급 등 잔액을 바꾸는 작업을 멈추고 진행 중인 지급을 마무리한다. 컷오버 시각을 고정하고 그 시각을 기준으로 보유 젤리와 잔액에 아직 반영되지 않은 미상환 대출금을 구분해 원본 스냅샷을 만든다.
3. 승인된 스냅샷을 관리용 일회성 작업으로 적용한다. 이관 ID와 사용자 ID의 고유 키를 남기고, 이관 기록과 젤칩 증가를 같은 D1 트랜잭션에서 처리한다. 같은 이관을 재실행해도 계정당 한 번만 가산한다.
4. 웹에 이미 있는 잔액과 당일 무료 지급 상태를 보존한다. 이관금은 베팅 승리나 시즌 획득량으로 집계하지 않는다.
5. 적용 전후 계정별 차이와 총합을 스냅샷에 대조하고 도감 겜블장의 잠금을 해제하고 이관 완료를 공지한다. 장애가 나면 같은 스냅샷으로 누락 계정만 이어서 적용한다. 원본 스냅샷과 적용 기록은 대조가 끝날 때까지 보관한다.

## 구현 확인 조건

종료 전 지급된 알바가 지갑 잔액에 한 번만 포함되는지, 미사용 알바가 제외되는지, 웹 잔액이 있는 멤버, 누락 및 채무 계정, 동일 이관 재실행, 중간 실패 뒤 재개를 확인한다. 잠금 중 직접 주소와 게임 요청이 차단되는지 확인한다. 배포나 PR 머지만으로 이관이나 잠금 해제가 실행되지 않게 한다.
