# 사라진 젤리 500개 — 원기록과 재구성

기존 연결 조사의 조작 순서 대신 상충하는 기록의 의미를 해석하는 사건으로 바꿨다. 세 방의 사진, 증언, 상자 안쪽 표찰, 자동 반출 기록 등을 자유로운 순서로 조사한다. 장부 작성 시각과 실제 이동 시각, 재사용한 바깥 번호와 재고 봉인 번호, 증언의 관찰 범위를 구분해야 한다. 사건 재구성판에서 이동 세 건의 시각·물품·도착지와 다섯 설명의 근거를 검증한다. 틀린 배치는 어긋난 항목을 알려 주고 기기에 초안을 남긴다.

- `src/jelly-mystery.ts`: 원기록 12개, 도입과 결말, 이동·해석·근거 검증. 기록으로 지지되는 대체 근거 조합도 허용한다.
- `src/views/jelly-mystery.tsx`, `src/views/tactile.tsx`, `src/views/story.tsx`: 기존 세 방 배경과 조력자 이미지를 재사용하고, 현장·수첩·재구성판을 연결한다.
- `public/tactile.js`, `public/styles.css`, `src/views/layout.tsx`: 가설 초안 보존, 근거 중복 안내, 검증 결과로 이동, 반응형 배치와 캐시 버전.
- `src/story.ts`, `src/tactile.ts`, `src/story-db.ts`: 새 젤리 사건만 v4로 시작한다. 진행 중 v2·v3 판의 영구 발견과 일지는 유지하고, 사건 사실이 바뀐 만큼 현장 원기록은 새로 조사한다. 완료 기록과 최초 보상 기준은 유지한다. 별도 D1 마이그레이션은 없다.
- `test/jelly-flow.test.ts`, `test/tactile.test.ts`, `scripts/story-smoke.mjs`: 해답의 구성 요소, 모순 응답, 근거 조작 및 구 버전 우회 거부, 재제출과 재플레이의 중복 보상 방지 검사.

TypeScript·스크립트 문법 검사, 자동 테스트 194개, 로컬 Workers/D1 HTTP 검사 42개 통과. 브라우저에서 전체 조사, 오배치 후 초안 유지, 수정 후 해결 확인. 320px 및 1100px 창 너비에서 가로 넘침 없음, 좁은 화면의 방 탭 한 줄 확인. 실물 휴대폰 및 운영 D1은 별도 확인 범위다. 운영 배포 없음.
