# 11/21 점검 보상 주기

나리 2026-11-19 결정, 2026-11-21 약 절반으로 줄임(겜블장 하루 채우기가 0개일 때 300개로 바뀌어서). 웹이 실제로 닫혀 있던 시간(점검 화면을 켠 때 ~ 끈 때)으로 칸을 골라요. 경계는 아래 칸이에요.

| 웹이 닫혀 있던 시간 | 도감 젤리 | 원정대 재료 | 젤칩 |
|---|---|---|---|
| 1시간까지 | 1 | 열린 장마다 1개씩 | 100 |
| 1~3시간 | 1 | 열린 장마다 1개씩 | 300 |
| 3~6시간 | 2 | 열린 장마다 1개씩 | 500 |
| 6~12시간 | 2 | 열린 장마다 2개씩 | 700 |
| 12시간 넘게 | 3 | 열린 장마다 2개씩 | 1,000 |

- 받는 사람: 실행할 때 웹 도감에 있는 멤버 모두(떠난 멤버 빼고) 똑같이.
- 열린 장: 원정대 재료 기록이 있는 가장 뒤 장까지 1장부터 전부. 원정대를 안 해 본 사람은 1장 재료.
- 젤코인은 주지 않아요(많이 쌓여 있고 재료가 모자라서 못 쓰는 상태라서).
- 디스코드 축하 글은 올리지 않아요. 멤버마다 웹 🔔 알림 하나만 가요. 공지는 나리가 공지 채널에 한 번.

## 순서 (반드시 이 순서)

1. `docs/gamble-jelly-move.md` 순서대로 겜블장 초기화(`scripts/gamble-reset.sql`)와 젤리 → 젤칩 이전을 끝내요.
   젤칩 보상을 먼저 주면 초기화 때 같이 지워져요. 그래서 이전이 안 끝났으면 보상 SQL이 첫 줄에서 멈춰요.
2. 점검 화면을 끄고, 실제로 닫혀 있던 시간을 재요.
3. `node scripts/maintenance-reward.mjs <시간> > maintenance-reward.sql` (예: 2시간 반이면 `2.5`)
4. `npx wrangler d1 execute haribo-dogam --remote --file maintenance-reward.sql`
5. 확인: `SELECT COUNT(*) FROM jelly_grants WHERE id LIKE 'maint-2026-11-21:%'` = 지금 멤버 수.

같은 파일을 다시 실행해도 이미 받은 사람(지급 기록이 있는 사람)은 다시 받지 않아요. 알림을 지워도 마찬가지예요.
