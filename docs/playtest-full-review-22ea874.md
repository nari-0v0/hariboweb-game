## 발견 사항

### 원정대 결과의 젤코인 보관율 대비가 낮음

원정을 클리어하고 결과 화면에서 이전 장의 젤코인 보관율(예: `🪙 100%`)을 확인한다. `.jr-farm`의 글자색 `#6b5a72`가 결과 화면의 장 카드 배경 `#3b3556` 위에 표시되어 대비가 **1.82:1**이다. 일반 텍스트 기준인 **4.5:1**보다 낮다. 전체 실행에서 3회, 원정대 보충 실행에서 같은 표시가 10회 기록됐다. 예시 캡처는 `codex-full/expedition-ch1-result.png`다. [표시 코드](../src/views/journey.tsx#L493-L496) · [장 카드 배경](../public/styles.css#L1421) · [보관율 글자색](../public/styles.css#L2215)

### 원정 종료 직전에 로봇이 자동 체크박스를 기다리다 중단

전체 실행은 `expedition/ch3/rev-null`, 원정대 보충 실행은 `expedition/ch5/rev-null`에서 `locator.uncheck`가 6초 뒤 실패했다. 루프는 결과 화면을 먼저 확인하지만, 다음 순번 읽기에 실패하면 `null`을 새로운 순번으로 취급하고 체크박스를 기다린다. 결과 화면으로 전환되는 사이에 발생할 수 있는 자동화 문제다. 두 실행 결과만으로 3장 또는 5장의 게임 진행 버그를 확정할 수 없다. 겜블장 보충 검사는 별도로 완료했고 원정대 5–9장은 클리어를 검증하지 못했다. [로봇의 원정 검사 루프](../scripts/playtest.mjs#L652-L683)

## 실행 기록

세 로컬 서버는 각각 종료됐다. 전체 실행과 원정대 보충 실행은 위 오류로 종료 코드 1을 반환했다. 겜블장 보충 결과에는 경고가 없었다. 원본 JSON과 스크린샷은 `output/playtest/` 아래 각 실행 이름의 디렉터리에 저장했다. 전체 실행은 PNG 1,229장, 원정대 보충은 324장, 겜블장 보충은 16장이다. 겜블장 검사는 게임당 한 판이며 원정대의 모든 무작위 분기, 실제 모바일 기기, 다른 브라우저는 검증 범위 밖이다.
